## 一、搬瓦工是什么，以及这几年它都经历了什么

搬瓦工的英文名是 BandwagonHost，隶属于成立于2004年的加拿大 IT7 Networks 公司。之所以被叫成"搬瓦工"，纯粹是因为英文拼音 ban-wa-gong 和 BandwagonHost 读起来高度神似——这个歪打正着的绰号反而让它在国内圈子里混得风生水起。

这几年下来，搬瓦工的变化还真不小。早年那个靠超低价OpenVZ打天下的形象早就不在了，现在全系改用KVM架构，价格也从几十块一年涨到了现在的入门款将近三百块人民币。套餐越来越多，从基础KVM到CN2 GIA-E到香港/东京超高端线路，再到企业级SLA套餐，几乎把每个预算区间都给覆盖了。

变化中有一件大事值得一提：从2025年11月双十一开始，搬瓦工悄悄取消了几乎所有的长期优惠码，包括之前流传多年的 `BWHCGLUKKB`。2026年初曾短暂出现过一枚新码 `NODESEEK2026`（6.77%循环折扣），但没过两天就失效了。截至目前，常规优惠码处于空窗期，想省钱就得盯限量版套餐或者等大促节点。

## 四、搬瓦工VPS教程第二步：登录后台，获取SSH信息

买完之后，搬瓦工会发一封确认邮件，里面有你的VPS信息入口。登录账号后进入 Services → My Services，找到你刚购买的VPS，点击 KiwiVM Control Panel 按钮进入搬瓦工自研的管理面板。

KiwiVM是搬瓦工的一大特色，功能相当完整：开关机、重装系统、rDNS设置、快照、流量统计、机房迁移、API接口，基本都能在这里搞定，不需要依赖第三方面板。

**获取SSH登录信息的步骤：**

在KiwiVM主页面可以直接看到 IP Address 和 SSH Port（搬瓦工的SSH端口是随机生成的，不是默认22，这点一定要注意）。

如果需要获取或重置root密码，在KiwiVM左侧菜单找到 Root password modification，先把VPS关机，然后点击生成新密码。新密码只会出现一次，记得马上复制保存。

**SSH连接工具推荐：**

Windows用户推荐用 Termius，界面友好，支持跨平台配置同步，比老牌的Xshell更现代一些。当然Xshell、PuTTY、Git Bash、PowerShell也都能用，看个人习惯。

Mac用户直接用系统自带终端即可，命令格式如下：

bash
ssh root@你的IP地址 -p 你的SSH端口


举个例子长这样：`ssh root@172.80.80.20 -p 27565`

如果本地实在连不上，或者IP被封了，还可以用KiwiVM里的 Root shell - interactive 功能，直接在浏览器里通过VNC远程连接，这个功能在应急救援时非常好用。

## 五、搬瓦工VPS教程第三步：系统初始化与环境部署

SSH连上去之后，你会看到一个空白的Linux命令行，接下来怎么搞取决于你的用途。

**如果是建站（WordPress/LNMP）：**

推荐先安装宝塔面板，一行命令搞定环境，对不熟悉Linux的朋友来说最友好。宝塔支持Nginx、Apache、MySQL、PHP的图形化管理，建站流程可以简化到几步点击完成。

LNMP一键包也是常用的老牌选择，命令行操作，更轻量，资源占用更低。

**如果是部署Docker应用（Dify、n8n、OpenClaw等）：**

先确认内存够不够，Dify建议至少2GB内存，n8n最低1GB可以跑，OpenClaw对内存要求更高一些。搬瓦工CN2 GIA-E套餐最低配置是512MB内存，跑这类AI应用可能稍显吃力，建议选高一档的配置。

**如果是学Linux基础操作：**

买个最便宜的KVM入门套餐就够用了，随便折腾，出问题了直接在KiwiVM重装系统，几分钟就能恢复。

**系统选择建议：**

搬瓦工提供Debian、Ubuntu、CentOS等多个发行版。CentOS 7官方已停止维护，推荐首选Debian 11/12或者Ubuntu 22.04 LTS，稳定且社区资源丰富。

## 六、搬瓦工VPS教程第四步：机房迁移与线路调优

买了CN2 GIA-E套餐之后，后台切换机房是日常操作。在KiwiVM左侧找到 Migrate to different datacenter，选择目标机房，点击确认就开始迁移了。整个过程通常只需要几分钟，只迁移已占用的磁盘扇区，数据安全。

**机房怎么选？** 简单说：

电信用户→ DC6 CN2 GIA-E 或 DC9 CN2 GIA 效果最好；联通用户→ 荷兰EUNL_9（AS9929）或日本大阪软银表现出色；移动用户→ 日本大阪JPOS_1软银或日本东京CMI线路最流畅。

如果不确定，可以在KiwiVM里查看当前机房的ping延迟，或者用搬瓦工官方提供的各机房测试IP进行网络测速，再决定迁到哪里。

## 九、搬瓦工VPS常见问题快速解答

**Q：搬瓦工的SSH端口不是22，应该去哪里找？**

在KiwiVM控制面板主页面，Main Controls区域，IP Address下面就是SSH Port，每台VPS的端口都是随机生成的。

**Q：IP被封了怎么办？**

可以在KiwiVM里付费更换IP，费用是8美元一次。如果是SLA套餐，每两周可以免费换一次。实在连不上的时候，先用KiwiVM的VNC功能（Root shell - interactive）应急登录处理。

**Q：系统重装之后原来的数据还在吗？**

不在了，重装会清空数据。建议在重装前先在KiwiVM创建快照备份，搬瓦工提供免费自动备份功能，每6天一次快照，可以在Backups里查看。

**Q：买哪个套餐最不容易后悔？**

选择困难就直接上CN2 GIA-E套餐，季付$49.99的入门价，12个以上机房随便切，不论是建站、部署应用还是日常使用，这条线路的容错率最高，买错机房了迁过去就行。
