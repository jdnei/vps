## 1. BandwagonHost چیست و در سال‌های اخیر چه تغییراتی کرده است؟

BandwagonHost که در میان کاربران چینی با نام «搬瓦工» یا «Banwagong» شناخته می‌شود، یکی از ارائه‌دهندگان خدمات VPS است که زیرمجموعه شرکت کانادایی IT7 Networks محسوب می‌شود. این شرکت در سال 2004 تأسیس شده است.

نام چینی «搬瓦工» در واقع از شباهت تلفظ عبارت «ban-wa-gong» با نام انگلیسی BandwagonHost گرفته شده است. این نام مستعار به‌طور اتفاقی ایجاد شد، اما به‌مرور در جامعه کاربران VPS چین بسیار محبوب شد.

BandwagonHost در چند سال اخیر تغییرات قابل‌توجهی داشته است.

در گذشته، این شرکت بیشتر به‌خاطر سرورهای مجازی بسیار ارزان‌قیمت مبتنی بر OpenVZ شناخته می‌شد، اما آن دوران به پایان رسیده است.

اکنون تمام محصولات آن از فناوری مجازی‌سازی KVM استفاده می‌کنند و قیمت‌ها نیز از چند ده یوان در سال به نزدیک 300 یوان برای ارزان‌ترین اشتراک سالانه افزایش یافته‌اند.

تنوع محصولات نیز بیشتر شده است. از VPSهای پایه KVM گرفته تا مسیرهای بهینه‌شده CN2 GIA-E، سرورهای پیشرفته هنگ‌کنگ و توکیو و حتی طرح‌های سازمانی دارای ضمانت SLA، تقریباً برای هر سطح بودجه گزینه‌ای وجود دارد.

یکی از تغییرات مهم، حذف کدهای تخفیف قدیمی بوده است.

از زمان جشنواره خرید 11 نوامبر 2025، BandwagonHost تقریباً تمام کدهای تخفیف بلندمدت خود، از جمله کد معروف `BWHCGLUKKB` را بی‌سروصدا غیرفعال کرد.

در اوایل سال 2026 کد جدیدی با نام `NODESEEK2026` برای مدت کوتاهی ارائه شد که 6.77% تخفیف تکرارشونده داشت، اما پس از چند روز از کار افتاد.

تا زمان این به‌روزرسانی، کد تخفیف عمومی فعالی وجود ندارد.

اگر می‌خواهید با قیمت پایین‌تری خرید کنید، بهتر است طرح‌های محدود یا جشنواره‌های تخفیف ویژه را دنبال کنید.

بسیاری از کاربران تازه‌کار هنگام مطالعه آموزش VPS شرکت BandwagonHost مستقیماً سراغ بخش اتصال SSH می‌روند، اما پس از خرید متوجه می‌شوند که طرح نامناسبی انتخاب کرده‌اند.

بنابراین، پیش از شروع مراحل فنی، بهتر است با دسته‌بندی محصولات آشنا شوید.

طرح‌های معمول BandwagonHost به چند گروه اصلی تقسیم می‌شوند:

**Basic VPS (طرح‌های پایه و اقتصادی):**

این سرورها از فناوری KVM استفاده می‌کنند و امکان جابه‌جایی بین چندین دیتاسنتر در لس‌آنجلس را فراهم می‌سازند.

این گروه ارزان‌ترین گزینه است و برای یادگیری Linux، میزبانی وب‌سایت‌های کوچک با ترافیک محدود و تمرین مدیریت سرور مناسب است.

قیمت ارزان‌ترین طرح پایه از **49.99 دلار در سال** شروع می‌شود.

**E-Commerce VPS / CN2 GIA-E (بهترین تعادل قیمت و عملکرد):**

این گروه یکی از محبوب‌ترین محصولات BandwagonHost محسوب می‌شود.

کاربران می‌توانند از طریق پنل مدیریت، بدون پرداخت هزینه اضافی، بین بیش از 12 دیتاسنتر جابه‌جا شوند.

از جمله دیتاسنترهای قابل انتخاب:

این سرورها در دیتاسنتر DC5 لس‌آنجلس قرار دارند و از منابع CPU اختصاصی AMD، حافظه ECC و فضای ذخیره‌سازی NVMe RAID-10 SSD استفاده می‌کنند.

این سرویس دارای **تضمین SLA برابر با 99.99%** است.

همچنین کاربران می‌توانند هر دو هفته یک‌بار آدرس IP سرور خود را به‌صورت رایگان تغییر دهند.

این گروه برای پروژه‌های تجاری با نیاز به دسترس‌پذیری بالا مناسب است.

**Ultra VPS (سرورهای پیشرفته با تأخیر بسیار پایین):**

حتماً یک آدرس ایمیل معتبر وارد کنید، زیرا اطلاعات مهم سرور VPS از طریق ایمیل ارسال می‌شوند.

اطلاعات کشور باید تا حد امکان واقعی باشند. آدرس شخصی لازم نیست بیش از حد دقیق باشد، اما نباید با شرایط واقعی شما اختلاف غیرمنطقی داشته باشد.

هنگام انتخاب طرح، وب‌سایت از شما می‌خواهد دوره پرداخت و محل دیتاسنتر را انتخاب کنید.

بنابراین لازم نیست در مرحله خرید بیش از حد برای انتخاب دیتاسنتر وقت بگذارید.

**روش‌های پرداخت:**

BandwagonHost از Alipay پشتیبانی می‌کند و پرداخت را برای کاربران داخل چین آسان‌تر کرده است.

برای خرید نیازی به واسطه یا تهیه کارت اعتباری بین‌المللی ندارید.

## 4. آموزش VPS شرکت BandwagonHost – مرحله دوم: ورود به پنل و دریافت اطلاعات SSH

پس از خرید، BandwagonHost یک ایمیل تأیید ارسال می‌کند که حاوی اطلاعات دسترسی به سرور VPS شما است.

وارد حساب کاربری خود شوید و مسیر زیر را دنبال کنید:

`Services → My Services`

سروری را که خریداری کرده‌اید پیدا کنید و روی دکمه **KiwiVM Control Panel** کلیک کنید.

با این کار وارد پنل مدیریت اختصاصی BandwagonHost می‌شوید.

KiwiVM یکی از ویژگی‌های مهم BandwagonHost است و امکانات متنوعی ارائه می‌دهد، از جمله:

- روشن، خاموش و راه‌اندازی مجدد سرور
- نصب مجدد سیستم‌عامل
- تنظیم DNS معکوس (rDNS)
- ایجاد Snapshot
- مشاهده میزان مصرف ترافیک
- انتقال سرور بین دیتاسنترها
- دسترسی به API

بیشتر کارهای مدیریتی را می‌توان مستقیماً از طریق KiwiVM انجام داد و نیازی به نصب پنل‌های جانبی نیست.

### نحوه پیدا کردن اطلاعات ورود SSH

در صفحه اصلی KiwiVM می‌توانید اطلاعات زیر را مشاهده کنید:

- `IP Address`
- `SSH Port`

**نکته مهم:** پورت SSH در BandwagonHost معمولاً به‌صورت تصادفی تعیین می‌شود و الزاماً پورت پیش‌فرض `22` نیست.

هنگام اتصال باید پورت صحیح را وارد کنید.

### نحوه بازنشانی رمز عبور Root

اگر لازم است رمز عبور کاربر root را دریافت یا بازنشانی کنید:

1. وارد پنل KiwiVM شوید.
2. از منوی سمت چپ گزینه `Root password modification` را انتخاب کنید.
3. سرور VPS را خاموش کنید.
4. گزینه ایجاد رمز عبور جدید را انتخاب کنید.
5. رمز عبور ایجادشده را فوراً کپی کرده و در محل امنی ذخیره کنید.

رمز جدید فقط یک‌بار نمایش داده می‌شود؛ بنابراین پیش از خروج از صفحه حتماً آن را ذخیره کنید.

### ابزارهای پیشنهادی برای اتصال SSH

**برای Windows:**

من استفاده از **Termius** را پیشنهاد می‌کنم، زیرا رابط کاربری ساده‌ای دارد و از همگام‌سازی تنظیمات میان پلتفرم‌های مختلف پشتیبانی می‌کند.

در مقایسه با ابزارهای قدیمی مانند Xshell، تجربه کاربری مدرن‌تری ارائه می‌دهد.

البته ابزارهای زیر نیز قابل استفاده هستند:

- Xshell
- PuTTY
- Git Bash
- PowerShell

انتخاب نهایی به سلیقه و عادت شما بستگی دارد.

**برای macOS:**

می‌توانید مستقیماً از برنامه Terminal خود سیستم‌عامل استفاده کنید.

فرمت دستور اتصال SSH به‌صورت زیر است:

```bash
ssh root@YOUR_SERVER_IP -p YOUR_SSH_PORT
```

برای مثال:

```bash
ssh root@172.80.80.20 -p 27565
```

### اگر اتصال SSH برقرار نشد چه باید کرد؟

اگر از شبکه محلی خود نمی‌توانید به سرور متصل شوید یا آدرس IP سرور مسدود شده است، می‌توانید از قابلیت زیر در KiwiVM استفاده کنید:

`Root shell - interactive`

این قابلیت امکان دسترسی به سرور از طریق کنسول VNC در مرورگر را فراهم می‌کند.

برای عیب‌یابی اضطراری و بازیابی دسترسی زمانی که SSH در دسترس نیست، بسیار کاربردی است.

## 5. آموزش VPS شرکت BandwagonHost – مرحله سوم: راه‌اندازی اولیه سیستم و نصب برنامه‌ها

پس از اتصال موفق با SSH، یک محیط خط فرمان Linux مشاهده خواهید کرد.

مراحل بعدی به هدف شما از استفاده از VPS بستگی دارد.

### اگر قصد راه‌اندازی وب‌سایت دارید (WordPress / LNMP)

برای کاربرانی که آشنایی زیادی با Linux ندارند، ابتدا نصب **پنل BT یا BaoTa Panel** را پیشنهاد می‌کنم.

این پنل نصب محیط میزبانی وب را ساده می‌کند و رابط گرافیکی برای مدیریت موارد زیر ارائه می‌دهد:

- Nginx
- Apache
- MySQL
- PHP

با استفاده از این پنل می‌توان بسیاری از مراحل راه‌اندازی وب‌سایت را تنها با چند کلیک انجام داد.

بسته نصب خودکار **LNMP** نیز یکی دیگر از گزینه‌های شناخته‌شده است.

این روش مبتنی بر خط فرمان است، سبک‌تر اجرا می‌شود و معمولاً منابع کمتری مصرف می‌کند.

### اگر می‌خواهید برنامه‌های Docker را اجرا کنید (Dify، n8n، OpenClaw و غیره)

قبل از نصب برنامه‌های مبتنی بر Docker، بررسی کنید که VPS شما حافظه RAM کافی داشته باشد.

به‌عنوان راهنمای کلی:

- **Dify:** حداقل 2GB حافظه RAM پیشنهاد می‌شود.
- **n8n:** نصب‌های ساده می‌توانند با حدود 1GB حافظه RAM اجرا شوند.
- **OpenClaw:** بسته به نوع نصب و تنظیمات، ممکن است به حافظه بیشتری نیاز داشته باشد.

برخی از طرح‌های پایه CN2 GIA-E تنها 512MB حافظه RAM دارند که برای اجرای این نوع برنامه‌های مرتبط با هوش مصنوعی ممکن است کافی نباشد.

برای چنین کاربردهایی بهتر است سروری با حافظه بالاتر انتخاب کنید.

### اگر فقط می‌خواهید Linux یاد بگیرید

ارزان‌ترین طرح پایه KVM کافی است.

می‌توانید دستورات مختلف را امتحان کنید، بسته‌های نرم‌افزاری نصب کنید، سرویس‌ها را تنظیم کنید و مدیریت سرور را یاد بگیرید.

اگر مشکلی پیش آمد، کافی است از طریق KiwiVM سیستم‌عامل را دوباره نصب کنید تا ظرف چند دقیقه یک محیط تمیز و آماده داشته باشید.

### سیستم‌عامل‌های پیشنهادی

BandwagonHost چندین توزیع Linux ارائه می‌دهد، از جمله:

- Debian
- Ubuntu
- CentOS

**پشتیبانی رسمی CentOS 7 به پایان رسیده است و دیگر به‌روزرسانی‌های نگهداری رسمی دریافت نمی‌کند.**

برای بیشتر کاربران، Debian 11/12 یا Ubuntu 22.04 LTS را پیشنهاد می‌کنم، زیرا پایدار هستند و مستندات آموزشی و منابع جامعه کاربری فراوانی دارند.
